# Security policy

## Reporting a vulnerability

Please report potential vulnerabilities privately through
[GitHub Security Advisories](https://github.com/ericrosenn1/LitDataMatcher/security/advisories/new).
Do not include credentials, private datasets, or personally identifying data in
an issue or a public discussion.

This repository has no guaranteed response-time service level. Reports should
include a minimal reproduction, affected version or commit, impact, and any
safe mitigation already identified.

## Supported versions

Security fixes are assessed against the default branch and the most recent
published release. A v0.4 release will be added here only after it is formally
released.
