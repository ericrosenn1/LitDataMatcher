# Legacy Literature Code

This folder preserves the original literature-analysis prototype for provenance
and future cannibalization. It is not the canonical production path.

Use `litdatamatcher/literature.py`, `litdatamatcher/text.py`, and
`litdatamatcher/schemas.py` for current package development. The files here were
moved without scientific-behavior changes so useful extraction logic, model
schemas, and historical tests can be reviewed before any future migration.
