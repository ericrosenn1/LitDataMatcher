# Development status

This branch contains repository infrastructure prepared separately from the
active v0.4 campaign. It must not be interpreted as a v0.4 release candidate.

The final release, PyPI publication, Zenodo deposit, DOI badge, release badge,
and live documentation badge are intentionally deferred until the v0.4 campaign
reaches `FEATURE_COMPLETE`, final source changes are integrated, and the
corresponding validation and external-service steps succeed.

The source of truth for current development is the repository's active
development branch and its validated campaign records, not this infrastructure
branch.
