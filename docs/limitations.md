# Scientific limitations

LitDataMatcher prioritizes literature-derived question-data opportunities for
expert review. It does not prove that a public dataset can answer a question.

- Extraction and ranking outputs require human review for scientific relevance.
- Metadata fit does not establish causal answerability, statistical power,
  independence, consent, license, or variable compatibility.
- Missing capability evidence remains unknown rather than being treated as
  absent.
- Heuristic scores are not calibrated effect estimates or clinical decisions.
- Production source adapters and corpora require their own provenance,
  access, and validation checks.

Read the repository's reproducibility and model-robustness documentation before
using outputs in a scientific claim.
