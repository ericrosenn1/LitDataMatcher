# Question compiler

The v0.4 question-to-data-requirements compiler is under active development on
the separate `codex/litdatamatcher-v2-build` branch. It is not a released or
finalized feature in this infrastructure branch.

To avoid presenting unfinished scientific behavior as stable public software,
this documentation site deliberately links the final compiler documentation
only after the v0.4 campaign reports `FEATURE_COMPLETE`, its validated source
state is integrated, and the release gates have passed.

The integration checklist requires the final documentation to describe the
compiler's source spans, provenance categories, underdetermined-question
behavior, strict assessor projection, and validation boundaries without making
claims beyond the final validated evidence.
