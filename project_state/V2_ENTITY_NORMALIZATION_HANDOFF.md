# Entity normalization tranche

Local deterministic identifier contracts cover genes/proteins, diseases/conditions, interventions/chemicals, tissues/cell types, organisms, assays, and experimental conditions. Each mapping records source, status, mapping type, and candidate IDs. `RESOLVED` exact/synonym mappings can support requirement comparison; ambiguous, unresolved, deprecated, orthologous, and source-unavailable values remain reviewable/unknown.

These bounded local fixtures are interfaces for future qualified ontology sources, not a claim of comprehensive ontology coverage or an instruction to force identifiers.
